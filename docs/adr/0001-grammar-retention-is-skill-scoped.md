# Grammar retention is skill-scoped

Status: accepted

Grammar FSRS tracks one learner, language and existing grammar skill, while historical grammar mastery remains based on its current evidence policy. A skill-level schedule avoids adding an unmaintained subskill taxonomy; because varied questions do not behave like a single fixed flashcard prompt, retention estimates and the below-target warning remain explicitly experimental until delayed recall and unseen equivalent questions validate them. Reused questions can qualify for retention after an unaided answer even when existing mastery logic treats them as repeats.

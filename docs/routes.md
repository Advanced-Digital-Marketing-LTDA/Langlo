# Foundation route policy

| Route                        | Audience and access                              | Indexing/cache                                         | Mutation and analytics                                                                                           | Verification                                           |
| ---------------------------- | ------------------------------------------------ | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| /                            | Public local foundation explanation              | Public; no-store during foundation                     | Read only; no analytics                                                                                          | Built browser desktop/mobile                           |
| /help                        | Public setup status                              | Public; no-store                                       | Read only; no analytics                                                                                          | Keyboard/navigation/history                            |
| /privacy                     | Public implementation/privacy status             | Public; no-store                                       | Read only; no analytics                                                                                          | Disclosure review                                      |
| /login                       | Sign-in form (Better Auth email/password)        | noindex/nofollow; private no-store                     | Registered credentials; uniform failure for unknown/wrong credentials; database rate limit                       | Built browser desktop/mobile                           |
| /recover                     | Password recovery request form                   | noindex/nofollow; private no-store                     | Uniform response for known/unknown email; database rate limit; safe unavailable response for invalid mail config | Built browser desktop/mobile                           |
| /reset                       | Password reset form (token in path)              | noindex/nofollow; private no-store                     | Single-use atomic redemption; expired/replayed tokens reject; revokes sessions                                   | Built browser desktop/mobile                           |
| /api/auth/**                 | Better Auth endpoints                            | noindex/nofollow; private no-store                     | Public email/password signup, sign-in/out and password reset; data/auth failures return safe feature errors      | Direct HTTP tests                                      |
| /signup                      | Public account registration                      | noindex/nofollow; private no-store                     | Requires working data/auth; SMTP is not a signup prerequisite; signup rate-limited                               | UI and direct API tests                                |
| /app and /app/**             | Private learner surfaces                         | noindex/nofollow; private no-store on redirects/errors | Signed-out GET redirects /login; unauthenticated mutation returns 401; safe 503 when data/auth unavailable       | Direct GET/POST tests                                  |
| /prototype and /prototype/** | T005 design prototype screens, synthetic data    | noindex/nofollow; no-store                             | Read only; no persistence, no learner data, no backend features                                                  | Built browser desktop/mobile                           |
| /health/live                 | Public process liveness independent of config/DB | noindex; no-store                                      | Read only; no analytics                                                                                          | Built HTTP 200, unique server-generated correlation ID |
| /health/ready                | Public safe readiness                            | noindex; no-store                                      | Safe 503 foundation-in-progress; never claims provider/schema readiness                                          | Built HTTP                                             |
| /build.json                  | Public safe revision                             | noindex; no-store                                      | Read only; no analytics                                                                                          | unknown unless explicit validated SHA                  |
| Unknown routes               | Public safe unavailable page                     | no-store                                               | No input echo; no analytics                                                                                      | Query/token/answer sentinel exclusion                  |

The private route guard is deny-by-default: without a verified database session `/app/**` GET redirects to `/login` and mutations return 401. If auth cannot be resolved because data/auth configuration or the provider is unavailable, private routes return safe 503s. Database tables alone do not establish privacy isolation of an API or usable learner journeys; T011 still owns query-authorization hardening. Only local fixtures are used in this slice.

T010b implemented the initial contract from [auth.md](auth.md): Better Auth 1.7.7 serves `/api/auth/**`, real `/login` `/recover` `/reset` forms replace the placeholders, and a minimal `/app` landing with sign-out exists. The owner revised the registration policy on 2026-10-13; this branch adds `/signup` and isolates mail/config failures by feature. Prototype routes under `/prototype` remain synthetic and unaffected. Cross-owner route acceptance remains pending.

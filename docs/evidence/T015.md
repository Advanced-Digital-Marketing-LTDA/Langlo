# T015 / LANGLO-42 · Prepared-answer evaluation

Date: 2026-10-17. Branch `claude/project-thread-ilod5c`, from main after PR 89.

## Source

The archived prepared-answer evaluator and synthetic corpus named in the task were not found in this repository, its history or the project files. With the owner's approval the evaluator was rebuilt from the matching rule every checked content module states (`matching`), and the checked content itself is the corpus.

## What changed

- `src/lib/server/evaluation/prepared.ts`: `evaluatePrepared` compares an answer with the question's checked answer and rubric alternatives and returns `correct`, `incorrect` or `uncertain`. It makes no model calls. Version `prepared-1`.
- Typed formats (typed blank, translation, correction) ignore letter case, extra spaces, apostrophe style and a run of final `.`, `!` or `?` characters, exactly as the curriculum contract normalizes them. Accents (after NFC composition), inner punctuation and every other character count, so the grammar error itself is not normalised away. A typed answer that matches nothing is `uncertain`: the case the bounded fallback (LANGLO-43) evaluates.
- Multiple choice is `correct` only for the exact checked answer (strict string equality, no trimming or Unicode normalization); any other option is `incorrect`. Options are not accepted answers. The importer (`src/lib/server/content-import.ts`) now requires a multiple-choice answer to appear among its options exactly as written, and every option to already be in the trimmed, NFC form the lesson submits, so a correct pick always matches.
- A question without a stored answer (imported before answers were stored) is `uncertain`.
- `recordAttempt` (`src/lib/server/study.ts`) writes one `evaluations` row in the same transaction as a new attempt: evaluator `prepared-1`, rubric = the attempt's content version. A replayed submission writes nothing; a refused attempt writes no evaluation. A stored question whose format, answer or alternatives fail to parse is refused with a descriptive error and nothing is saved.

## Limits

- Near misses are used only by the corpus test; they are not stored, so a near-miss answer is `uncertain`, not `incorrect`, until the fallback evaluates it.
- The rule is the same for every track today; the corpus test fails loudly if a module states a different one.
- No learner-facing feedback, mastery or skill evidence is written (LANGLO-44 and LANGLO-45). Flashcard ratings and FSRS are untouched.

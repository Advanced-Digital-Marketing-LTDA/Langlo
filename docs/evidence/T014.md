# T014 / LANGLO-41 · The four exercise formats

Date: 2026-10-16. Branch `claude/project-thread-ilod5c`, from main after PR 86.

## What changed

- `src/lib/components/exercises/`: `answer.ts` (the answer check and per-language accent letters), `MultipleChoice.svelte`, `TextAnswer.svelte` and `Exercise.svelte`. Multiple choice is a labelled radio group; typed blank is one line; translation and correction are a text area. French and German get buttons for accented letters, inserted at the caret. Controls are at least 3rem high, so they work by touch.
- The lesson page `src/routes/app/learn/[language]/lesson/[skill]/` shows the next exercise when opened with `?session=<study session id>`, and has a typed form action `answer`. The practice logic (serving the next exercise, recording the answer) lives in `src/lib/server/lesson-practice.ts`.
- `describeLearnerError` in `learner-api.ts` gives the form action the same status and message the JSON routes use. `publicQuestion` types the question format.

## Behavior

- The action takes the learner only from the verified session. It reads the session's current question itself and refuses any other question id (409 `STALE_QUESTION`), then checks the answer against that question's format and options before `recordAttempt`. The answer is recorded as `independent` evidence.
- The answer check trims and composes accents (NFC), and refuses empty, blank, over 4096 characters, null bytes, a line break in a typed blank, and a multiple-choice answer that is not an offered option. A refused answer writes no attempt. The browser runs the same check for a quick message; the server decides.
- A retried submission (same key, same payload) gets the original attempt back (`duplicate: true`) even after the session has moved on, instead of a stale-question error; a different payload under the same key is a 409 conflict.
- The form action URL keeps `?session=` (`answerActionUrl`), so a submit without JavaScript lands back on the next question instead of dropping the practice form.
- No grading, mastery or flashcard code is touched. The page says only "Answer recorded."

## Tests

- `tests/exercise-answer.test.ts` (11) and the `lesson answer action` block in `tests/learner-routes.test.ts` (12). Full run on Node 24.19.0: 44 files, 901 tests passed; check, lint, format:check and build clean.
- Red check: with the empty and length checks removed from `checkAnswer`, 6 of these tests fail (empty, blank, limit). The oversized action test still passes then, because `recordAttempt` also refuses over-long answers.

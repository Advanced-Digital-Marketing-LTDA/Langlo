## Behavior

on the owner-scoped session. An A2 enrollment samples A1 foundations alongside
A2 topics; at most one untouched holdout per skill and 12 items total. Coverage
is stated, and no calibrated CEFR placement claim is made. Question IDs pin
versions across reload/import. Quarantine is checked again before submission.
Out-of-plan/out-of-order questions cannot be written. Final-answer recording
and session completion share one transaction. The start token and answer keys
make repeated submissions safe.

Both existing evaluation readers hide assessment evaluations until completion,
including direct attempt API reads. The assessment flow does not render a
lesson or expected answer before completion. Not sure is persisted separately
and stays uncertain even for multiple choice; it never invokes fallback.
Completed results show correct/incorrect/uncertain separately and identify A1
topics to revisit. No mastery or mistake card is written here.

Practice feedback is immediate and reload-safe. The retry form records assisted
evidence regardless of posted evidence kind. Re-presenting an item in another
session is also assisted. Practice cannot serve assessment feedback or holdouts.
Existing page controls/layouts are reused; synthetic prototype screens and
curriculum content are unchanged.

Migration `0013_assessment_feedback` adds nullable session plans and a false-by-
default not-sure flag without rebuilding tables or removing existing triggers.
Upgrade tests compare every pre-existing attempt field and evaluation, and
migration inventory expectations include the additive migration.

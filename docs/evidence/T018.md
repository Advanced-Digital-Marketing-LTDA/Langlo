# T018 / LANGLO-45: grammar mastery and recommendations

2026-10-17. Plan: `docs/plans/T018.md`. Policy: `docs/scoring-policy.md`.
Server-only implementation uses existing owner-scoped history and the existing
skill-evidence ledger; no new schema, provider call or scheduler change.

Status, qualifying counts, distinct sessions, policy version and a reason are
returned per skill. Only recognized certain independent grammar evaluations
qualify; incomplete assessments, assisted/repeated/not-sure/uncertain responses
and quarantined source items do not. A logical item counts once across versions.
The ledger records exact evaluation identity once per scoring version; current
totals are derived from trusted history, not from flashcard state or ledger sums.
Recommendations are deterministic and preserve manual topic choices.

Observed red: initial test collection failed for the missing module (not a
behavior red). After introducing empty service boundaries, 11 of 12 behavior
tests failed: nonempty histories remained unknown, no counts/evidence were
returned, and recommendations were absent. Green: the 12 behavior tests and two
property tests passed in two files (100 cases per property). Boundary tests cover the 60% weak and
80%/five-item/two-session secure rules; these are local heuristics with no
calibrated CEFR claim. Provider/release acceptance remains separate.

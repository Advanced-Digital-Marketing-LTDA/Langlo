# French A1 module 02: verbs in common use, negation and questions

Date: 2026-10-16. Skills fr-a1-005 to fr-a1-008. Content and tests only, on disposable local fixture databases. No provider, production database, credentials or learner data were used.

## Scope

Four English lessons, one per skill, in prerequisite order: frequent irregular verbs (aller, faire, prendre), `ne ... pas` negation, yes/no questions, and question words. Each lesson has an explanation, three examples, the references from the skill's catalog `source_ids`, and one content version with 12 practice items and 3 assessment holdouts across all four exercise formats (60 items). All items are original. The matching rule is the one declared in module 01.

The bundle, importer, schema and migrations are unchanged. The module is not imported anywhere; releasing it needs a new curriculum version, as for module 01.

# French A1 module 03: nouns, articles, adjectives and possessives

Date: 2026-10-16. Skills fr-a1-009 to fr-a1-012. Content and tests only, on disposable local fixture databases. No provider, production database, credentials or learner data were used.

## Scope

Four English lessons, one per skill, in prerequisite order: singular articles and noun gender, regular plurals and plural articles, adjective agreement and position, and possessive determiners. Each lesson has an explanation, three examples, the references from the skill's catalog `source_ids`, and one content version with 12 practice items and 3 assessment holdouts across all four exercise formats (60 items). All items are original. The matching rule is the one declared in module 01.

The bundle, importer, schema and migrations are unchanged. The module is not imported anywhere; releasing it needs a new curriculum version, as for module 01. It builds on module 02 only through the shared module test, so it is stacked on the branch of PR 45.

# English A1 module 03: plurals, articles, pronouns and possessives

Date: 2026-10-16. Skills en-a1-009 to en-a1-011. Content and tests only, on disposable local fixture databases. No provider, production database, credentials or learner data were used.

## Scope

4 English lessons, one per skill, in prerequisite order: plural nouns, articles and demonstratives, subject and object pronouns, and possessive determiners and pronouns. Each lesson has an explanation, three examples, the references from the skill's catalog `source_ids`, and one content version with 12 practice items and 3 assessment holdouts across all four exercise formats (60 items). All items are original. The matching rule is the one declared in French module 01.

The bundle, importer, schema and migrations are unchanged. The module is not imported anywhere; releasing it needs a new curriculum version, as for French module 01. It is stacked on the branch of module 02, because it relies on the shared module test introduced with French module 02.

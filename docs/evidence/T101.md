## Matching rule

Typed answers ignore letter case, extra spaces, apostrophe style and final `.`, `!` or `?`. Accents and every other character count, so `a` for `à` and `etudie` for `étudie` are rejected. Multiple-choice answers must match exactly. The rule lives in the module and the test; the app has no server-side evaluator yet (LANGLO-41 to 44).

## Import

The module is refused while unreviewed (`UNREVIEWED`, nothing written). With a recorded review, it imports with the approved 1.0.0 bundle's skills and prerequisites (the bundle has no content versions of its own) into a fresh fixture as 4 versions and 60 questions, and a second import adds nothing. When the approved bundle was already imported, the module imports on top of it only as a newer curriculum version (tested as 1.1.0), because the importer ties a curriculum version to one exact package. Releasing the module therefore needs a new curriculum version. The `questions` table has no payload column yet, so prompts and answers are validated but not stored. The importer also has no holdout flag, so holdouts would be stored as ordinary questions; keeping them out of practice is for the lesson runtime (LANGLO-40 onward).

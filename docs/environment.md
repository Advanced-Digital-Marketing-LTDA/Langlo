# Runtime environment registry

All application values are explicit private dynamic declarations in src/env.ts, exposed server-only through $app/env/private. hooks.server.ts validates them at the request boundary, except /health/live, which remains dependency-independent even when configuration is invalid. config.ts is server-only. No provider/account identifiers are embedded in client assets.

| Variable                            | Purpose                        | Scope                      | Default and validation                                                                                                          | Invalid behavior                                                  |
| ----------------------------------- | ------------------------------ | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| APP_ENV                             | Deployment boundary            | Private runtime            | development; development/test/production only                                                                                   | Safe configuration-unavailable response                           |
| APP_ORIGIN                          | App origin                     | Non-secret private runtime | localhost:3000 locally; explicit HTTPS in production; exact loopback hosts locally; no credentials/query/fragment/non-root path | Same                                                              |
| DATA_ENABLED                        | Selected DB feature            | Private runtime            | false; lowercase true/false only                                                                                                | Same                                                              |
| DATABASE_URL                        | App-isolated DB                | Secret private runtime     | Empty while disabled; local file in dev/test; dedicated libsql URL in production                                                | Required only when enabled; no connection attempted by foundation |
| TURSO_AUTH_TOKEN                    | Future remote DB auth          | Secret private runtime     | Empty; required for selected remote production DB                                                                               | Same; value never emitted                                         |
| APP_BUILD_SHA                       | Safe build revision            | Non-secret private runtime | unknown; exact lowercase 40-character SHA or unknown                                                                            | Same                                                              |
| HOST                                | Node listen interface          | Adapter runtime            | Local tooling uses 127.0.0.1                                                                                                    | Adapter validates; not exposed                                    |
| PORT                                | Node listen port               | Adapter runtime            | 3000; test server 4173                                                                                                          | Adapter validates                                                 |
| BODY_SIZE_LIMIT                     | Adapter request cap            | Adapter runtime            | Example 64K; operator must keep bounded                                                                                         | Adapter validates                                                 |
| BETTER_AUTH_SECRET                  | Auth token/cookie signing key  | Secret private runtime     | Empty; required ≥32 characters when data is enabled                                                                             | Safe configuration-unavailable response                           |
| MAIL_TRANSPORT                      | Recovery mail transport        | Private runtime            | capture; lowercase capture/smtp only                                                                                            | Same                                                              |
| MAIL_FROM                           | Recovery mail sender           | Private runtime            | Empty; required valid email when MAIL_TRANSPORT=smtp                                                                            | Same                                                              |
| PROTON_SMTP_TOKEN                   | Proton SMTP submission token   | Secret private runtime     | Empty; required when MAIL_TRANSPORT=smtp; value never emitted                                                                   | Same                                                              |
| SMTP_HOST                           | Proton submission host         | Private runtime            | smtp.protonmail.ch; bare hostname only, no credentials/path/port                                                                | Same                                                              |
| SMTP_PORT                           | Proton submission port         | Private runtime            | 587; integer 1–65535                                                                                                            | Same                                                              |
| MAIL_CAPTURE_DIR                    | File mail capture directory    | Private runtime            | In-memory capture when unset; absolute path under the system temp directory only                                                | Same                                                              |
| FC_NUM_RUNS                         | Property samples               | Test only                  | 100; positive safe integer                                                                                                      | Test failure                                                      |
| FC_SEED                             | Reproducible property seed     | Test only                  | Unset; signed 32-bit integer                                                                                                    | Test failure                                                      |
| FC_PATH                             | Property replay                | Test only                  | Unset; numeric colon path with seed                                                                                             | Test failure                                                      |
| PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH | Optional preinstalled Chromium | Test only                  | Unset in CI, /usr/bin/chromium in this environment                                                                              | Browser launch failure                                            |

No AI, analytics, billing, OAuth or Anki provider is activated. The SMTP transport is wired but has never been exercised against a live provider; capture remains the only verified mail path. Private environment configuration is not permission for live integration or production access. Storage resources and credentials must be provisioned separately under explicit authorization. APP_BUILD_SHA is safe provenance only, never evidence that a release occurred.

Framework/adapter sources inspected 2026-10-06: https://svelte.dev/docs/kit/adapter-node and https://svelte.dev/docs/kit/server-only-modules. Node adapter uses runtime environment; production .env loading requires an explicit documented operator mechanism. Reverse-proxy trust settings remain a deployment gate.
